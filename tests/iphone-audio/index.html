iPhone Audio Tests

Three short tests for the Class 5 sound examples. Scan each code with the phone.

Each test ends with a Copy results button. Paste the results into the chat. Results stay in the phone's browser until you clear them, so you can run a test again with a different setting and copy both runs together.

Test 1 · Speech Without a Tap Can the phone speak when a timer, a shake or a clap asks it to? Decides whether motion to speech and sound to speech are possible on iPhone.
Test 2 · Silent Mode Which kinds of sound silent mode mutes, and whether the playback session setting brings them back.
Test 3 · Mic and Speaker Together Where the sound comes out while the microphone is open, and how loudly the phone hears itself.
