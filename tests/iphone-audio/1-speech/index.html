Test 1 · Speech Without a Tap

Can the phone speak when a timer, a shake or a clap asks it to, instead of a finger?

Turn silent mode off and the volume up. Load this page fresh and do the steps in order. Step A only counts if nothing has spoken yet.

A · A timer, before anything has spoken

Tap to start a 3 second countdown. The tap itself says nothing. The phone speaks when the countdown ends.

B · A tap

The tap speaks straight away. This one should always work.

C · A timer, after a tap has spoken

The same countdown as A, now that B has spoken once.

D · A shake

Allow motion, then shake the phone. Each shake asks it to say "shake". Try a few.

E · A clap

Allow the microphone, then clap. Each clap past the red line asks it to say "clap". After each one it ignores claps for 3 seconds, so it does not set itself off.

F · A silent tap, then a timer

A found that the first sentence has to come from a tap. Can that tap be silent? Reload the page before each button, and do not press anything else first.
