Keep the file you work with under 2 MB. Several of these are larger. Above 2 MB the sketch is slow to open on a phone, and slower again with the whole room loading at once. ezgif resize changes the dimensions and ezgif optimize drops frames and colours, both in the browser with nothing to install.

How to use one in a sketch

  1. In the p5.js web editor, open the arrow beside Sketch Files and choose Upload file. Drop the GIF in.
  2. Load it in setup() with await, using the exact file name.
  3. Draw it in draw(). Drawing it is what makes it animate.
let gif;

async function setup() {
  createCanvas(windowWidth, windowHeight);
  imageMode(CENTER);

  // setup waits here until the file is ready
  gif = await loadImage('cow.gif');
}

function draw() {
  background(20);

  // drawing it is what plays it
  image(gif, width / 2, height / 2);
}
