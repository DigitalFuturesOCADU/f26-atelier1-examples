How a GIF behaves in p5.js
  • It is one p5.Image. It holds every frame and shows one at a time.
  • It only moves while you draw it. Each image() call checks the clock and steps the frame when its delay has passed.
  • Two canvases must never share one loaded GIF. Each canvas that draws it steps it again, so they fight. Every example on this page loads its own copy.
  • Frames count from 0. The last one is numFrames() - 1.
