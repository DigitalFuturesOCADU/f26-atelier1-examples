      Animated GIFs

      An animated GIF is a stack of frames with a timing for each one. In p5.js it loads like any other image, and it comes with seven extra methods for taking that timing into your own hands. Each example on this page is one complete sketch. Tap the demo to try it, copy the code, or open it on your phone.

      How a GIF works in p5.js

      • It is a p5.Image. loadImage() gives you one image object. It keeps every frame inside and shows one of them at a time. gif.width and gif.height work as usual.
      • It only moves while you draw it. Each call to image() checks the clock and switches to the next frame once its delay has passed. Stop drawing it and it stops. Draw the same GIF twice in one frame and it runs twice as fast. Give every canvas its own copy.
      • Every frame has a delay. The file sets a delay for each frame, in milliseconds. delay() replaces it.
      • Frames count from 0. The first frame is 0. The last one is numFrames() - 1.

      Loading a GIF

      p5.js 2.x loads files with async and await. Setup waits on that line until the file is ready, and draw() does not start until setup has finished. Every sketch below starts this way.

      let gif;

async function setup() {
  createCanvas(windowWidth, windowHeight);
  imageMode(CENTER);

  // setup waits here until the file is ready
  gif = await loadImage('stitch.gif');
}

function draw() {
  background(20);

  // drawing it is what makes it play
  image(gif, width / 2, height / 2);
}

      In the web editor, upload the GIF to the sketch files first. Then loadImage('yourfile.gif') finds it by name.

      Use one in your sketch

      1. Pick the example closest to what you want and copy its code with the copy button.
      2. In the web editor, make a new sketch and paste it over sketch.js.
      3. Open the sketch files panel, upload your GIF, and change 'stitch.gif' to its file name.
      4. For 08 and 09, also add the p5-phone script to index.html. Copy the line from the example's index.html.
      5. Test on the phone with the share link.
