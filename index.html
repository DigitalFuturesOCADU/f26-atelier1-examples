Class 5 · Making Sound

Seven small examples, one way of making sound each: a recording, a changed recording, an echo, a tone, a loop, an instrument and speech. Touch only. Tap once to turn on sound.

  • 01 Play a Recording code web editorLoad a recording and play it. Each tap starts it again. Uses p5.sound.
  • 02 Bend a Recording code web editorA loop. Left and right is the speed, and the pitch moves with it. Up and down is the volume. Uses p5.sound.
  • 03 Echo a Recording code web editorThe bell goes through an echo, p5.Delay. Where you tap sets the time between repeats and how many. Uses p5.sound.
  • 04 Make a Tone code web editorAn oscillator. Hold a finger down: left is low, right is high. Nothing was recorded. Uses p5.sound.
  • 05 Start a Loop code web editorEight notes loop on Tone's own clock. Drag to set the tempo. Uses Tone.js.
  • 06 Play an Instrument code web editorA sampled marimba. Tap a key to strike that note. Uses smplr.
  • 07 Say the Time code web editorThe phone's own voice says the time. Where you tap sets how fast and how high. Your phone has voices: tap the bar for the next one. Uses speechSynthesis.

Class 5 · Input to Sound

Six questions, each with a touch, a motion and a sound version. The sound part of the code is the same in all three. Only the input changes. Open the three on three phones and compare. Use headphones with the sound versions.

  • 01 Choice to RecordingWhich one? Four recordings: wait, mark, wake, go. Uses p5.sound.
    • Touch code web editorA finger picks one of four zones.
    • Motion code web editorHold it flat and tip it toward a corner.
    • Sound code web editorA low hum or a high whistle picks. Sound tells two kinds apart, not four. Only two recordings can play.
  • 02 Amount to SpeedHow much? One looping clock tick. Speed and pitch move together. Uses p5.sound.
    • Touch code web editorTwo fingers. Close is slow, far apart is fast.
    • Motion code web editorThe angle. Flat is slow, upright is fast.
    • Sound code web editorHow loud. Quiet is slow, loud is fast.
  • 03 Count to VoicesHow many? Five oscillator voices of one chord. Uses p5.sound.
    • Touch code web editorEach finger on the screen adds a voice.
    • Motion code web editorEach shake adds a voice for a few seconds. Shakes are counted over time, not at one moment.
    • Sound code web editorEach clap adds a voice for a few seconds. Claps are counted over time. The voices can cover them.
  • 04 Gap to TempoWhen? A metronome on its own clock. Uses Tone.js.
    • Touch code web editorTap a steady beat.
    • Motion code web editorShake a steady beat.
    • Sound code web editorClap a steady beat.
  • 05 Dial to NoteWhich note? A sampled marimba, one note of a scale. Uses smplr.
    • Touch code web editorTwo fingers turn the dial like a knob.
    • Motion code web editorLay the phone flat and turn it.
    • Sound code web editorHum low, then high.
  • 06 Hold to SpeechHow long? The phone says how long it lasted. Longer is slower. Uses speechSynthesis.
    • Touch code web editorHold a finger down, then let go.
    • Motion code web editorHold the phone upright, then lower it. The first words must come from a tap, not a movement.
    • Sound code web editorHum for a while, then stop. The first words must come from a tap. On a speaker it may time its own voice.

Class 10 · Cameras are Sensors

What a phone camera can notice, lightest first: pixels with no model, ml5 hand, face and body, MediaPipe gestures, and markers. Every camera example shows a red dot while the camera is on, and nothing is recorded. The full set, for laptop and phone, is browserCV.

  • 01 Color Tracking codeTap a colour in the camera image and follow it. No model.
  • 02 Brightness Tracking codeFollow the brightest spot, like a flashlight. No model.
  • 03 Motion Detection codeShow what moved since the last frame. Keep the camera still.
  • 04 Hand Pose codeFind a hand and its 21 points. Pinch to measure the distance. Uses ml5.
  • 05 Face Mesh codeFind a face and its 468 points. Open your mouth to fill the meter. Uses ml5.
  • 06 Body Pose codeFind a body and its 33 points. Raise an arm to light it up. Uses ml5.

  • 08 ArUco Markers codeShows every ArUco marker in view: its number, its turn and its size. Measures the distance and the angle between every pair.
  • 09 Marker on a Screen codeTap a number and your phone shows that marker, full screen. Hold it up to 08 next to the paper marker with the same number, and compare them. 0 to 36, or any number up to 249.
  • 11 Face Tracking codeBoxes every face in view. Made for a laptop at the front of a room. It finds faces, it does not know who anyone is. Add ?grid=8x5 to the address to reach the back of the room.

The AR ladder's other examples are in three-phone and browserCV, linked from Canvas.

  • The Creature on the Table codeA marker on each table, and a creature standing on it. Every phone sees the same creature in the same place. No network. Print ArUco marker 0 at 150 mm, one for each table. Another size: add ?size= and the width in mm. On a wall: add ?on=wall.

Class 12 · Many Phones, One Space

How p5-phone Share works, in small steps: Your Room, the Room Inspector, the smallest sketch and five Share Basics, and One Cow to Many. Then four class-wide examples. Each class-wide one is a projector page for the laptop at the front and a phone page for everyone else, joined by a QR code. Share keeps the last thing written, so each phone keeps its own value in me, and the projector adds them up. The class server runs in class. The room behind the Class Lamp in Class 13 is Share too. To run your own server, see Your Own Share Server on Canvas.

The folder keeps its old name, class-11/.

  • Your Room codeType the room you were given. It gives you every Share Basic opened in your room, a QR code for each, and a Room Inspector for each.
  • Room Inspector code web editorWatch a room: every page in it, everything each one sends, the room’s shared, and every event with who sent it. Add ?room= and ?app= to the address, or type them in.
  • One Number code web editorThe smallest Share sketch. Every phone sends one number, how many times it was tapped, and every phone shows everyone’s in a grid, with the id the room gave each phone. Four numbered comments: the four things every Share sketch does.
  • Share BasicsFive small sketches, one idea each, all built the same way. Each one has a ROOM line at the top. Open them from Your Room to use your own room.
    • 1 Who's Here code web editorJoin a room and see who else is in it. Each phone sends a name and a colour. shareJoined and shareLeft say who came and went.
    • 2 Send a Number code web editorEach phone sends one number, how loud it is around it, from 0 to 1. A laptop uses its own microphone.
    • 3 Send Several Things code web editorEach phone sends a name, a colour, and x and y from its tilt. Everyone is a dot on one field.
    • 4 Send Text code web editorEach phone sends what you type in the box, as you type it.
    • 5 Send an Event code web editorTap to knock. Every other phone gets a ripple where you tapped, and your name. shareEvent says who sent it.
  • One Cow to ManyOne sketch, six snapshots. A cow that steps when you shake the phone becomes a cow for each person in the room, on every phone. Each snapshot adds one idea. ROOM is cow: change it to your own room. On a laptop, click or press space for a shake.
    • 0 One Cow code web editorOne player, no room. Each shake is one step: the next frame, and one note of a climbing tune. The cow walks on the spot.
    • 1 Join a Room code web editorThe same cow, in a room. shareSetup and the start tap join it. The status line says you are in. Nothing is sent yet.
    • 2 Say Who You Are code web editorIdentity. me sends a name and a colour. A border in your colour and your name show which phone is yours.
    • 3 Everyone's Cow code web editorState. The steps go in me, so every phone draws every cow in its own lane. A late joiner sees each cow on the step it has reached.
    • 4 Hear Every Step code web editorEvent. Each step is sent with shareEmit, and every phone plays that cow’s note, at its owner’s pitch.
    • 5 Lean Together code web editorStream. Tilt left and right and your cow leans on every phone. A laptop uses the mouse. State, event and stream in one sketch.
  • 01 Crowd Tilt code web editorRolls one ball on the average tilt of every phone. Get it into the ring and hold it for half a second. Open it on the laptop at the front. Phones join with its QR code.
    • Phone page web editorYour tilt joins the crowd. Your dot is the same colour as your line on the big screen. Join it from the projector’s QR code, which carries the server and the room.
  • 02 Chord code web editorGives each phone one note of a chord and shows who is playing. Keys 1 to 4 change the chord. Open it on the laptop at the front. Phones join with its QR code.
    • Phone page web editorPlays one note. Raise the phone to play louder. Every phone together is the chord. Join it from the projector’s QR code, which carries the server and the room.
  • 03 Hot Potato code web editorOne potato, one phone at a time. Picks who catches it and keeps the clock. Open it on the laptop at the front. Phones join with its QR code.
    • Phone page web editorShake to throw the potato when it is on your phone. Do not hold it when time runs out. Join it from the projector’s QR code, which carries the server and the room.
  • 04 Show of Hands, Networked code web editorAdds up the Yes and No votes. It does not know where anyone is. Open it on the laptop at the front. Phones join with its QR code.

Class 13 · Talking to Things

Level 1, the basics: one phone and one Arduino Uno R4 WiFi over Bluetooth. Each example is a phone page and the board sketch it talks to, in the code folder under arduino/. Three send from the phone to the board, and two send from the board to the phone. Each page draws what the board will do before anything is connected. Chrome on Android or a laptop. On an iPhone, open it in the Bluefy app.

  • 01 LED On and Off codePhone to board. Tap the screen and an LED on D9 switches on or off. One true or false value, led.
  • 02 LED Brightness codePhone to board. Tilt the phone forward and back, and the LED on D9 dims from 0 to 255. One byte, brightness.
  • 03 Servo codePhone to board. Tilt left and right, and a servo on D10 turns from 0 to 180 degrees. One byte, angle.
  • 04 Button codeBoard to phone. A button on D2 fills the shape on the phone and counts presses. One true or false value, button.
  • 05 Light Sensor codeBoard to phone. A light sensor (LDR) on A0 sets how bright the phone screen is. One number from 0 to 1023, light.

Level 2 of talking to things: the hub. It uses a ready-made room on the class server, the Crowd Tilt room. You scan its QR code, tilt your phone and watch the lamp. How the room works (Share) was Class 12. Phones never pair. One laptop adds up their tilt and drives an Arduino R4 lamp over Bluetooth. The Arduino sketch is in the code folder.

  • The Class Lamp: Hub codeA laptop page joins the Crowd Tilt room, adds up every phone's tilt, and sends colour, brightness and pixel count to an R4 lamp over Bluetooth. Shows a preview with no lamp. Laptop in Chrome.

Class 14 · Traces and Residue

Memory between visits. The Wall keeps every mark in a Share room. With the keep option, coming in the next p5-phone release, the marks stay after everyone leaves. Until then it forgets when the last phone leaves, and it says so.

  • The Wall codeA wall the whole class adds to. Each tap on a phone leaves one dot in that phone's colour, and each dot fades over 24 hours. The wall says what it remembers. Open it on the laptop you share on the call. Phones join with its QR code.
    • Phone pageTap the wall to leave one mark, then wait for the ring before the next. Join it from the wall’s QR code, which carries the server and the room.

Class 15 · Organizing People

The phone organises the people. Conductor gives every phone a role and sends cues to everyone or to one role, and builds a session score as it goes. Read aloud mode puts the same cues on the projector for a person to say instead.

  • Conductor codeGives every phone a role (Red, Blue, Yellow or Green) and sends cues to everyone or to one role. Counts how many phones have shown each cue and builds a session score you can copy. Press M for Read aloud. Open it on the laptop at the front. Phones join with its QR code.
    • Phone pageShows your role as a colour, a shape and a name. A cue fills the screen and buzzes on Android. Two switches, both off, let it speak the cue or flash the light. Join it from the projector’s QR code.
