Class 5 · Making Sound

Seven small examples, one way of making sound each: a recording, a changed recording, an echo, a tone, a loop, an instrument and speech. Touch only. Tap once to turn on sound.

  • 01 Play a Recording code web editorLoad a recording and play it. Each tap starts it again. Uses p5.sound.
  • 02 Bend a Recording code web editorA loop. Left and right is the speed, and the pitch moves with it. Up and down is the volume. Uses p5.sound.
  • 03 Echo a Recording code web editorThe bell goes through an echo, p5.Delay. Where you tap sets the time between repeats and how many. Uses p5.sound.
  • 04 Make a Tone code web editorAn oscillator. Hold a finger down: left is low, right is high. Nothing was recorded. Uses p5.sound.
  • 05 Start a Loop code web editorEight notes loop on Tone's own clock. Drag to set the tempo. Uses Tone.js.
  • 06 Play an Instrument code web editorA sampled marimba. Tap a key to strike that note. Uses smplr.
  • 07 Say the Time code web editorThe phone's own voice says the time. Where you tap sets how fast and how high. Your phone has voices: tap the bar for the next one. Uses speechSynthesis.

Class 5 · Input to Sound

Six questions, each with a touch, a motion and a sound version. The sound part of the code is the same in all three. Only the input changes. Open the three on three phones and compare. Use headphones with the sound versions.

  • 01 Choice to RecordingWhich one? Four recordings: wait, mark, wake, go. Uses p5.sound.
    • Touch code web editorA finger picks one of four zones.
    • Motion code web editorHold it flat and tip it toward a corner.
    • Sound code web editorA low hum or a high whistle picks. Sound tells two kinds apart, not four. Only two recordings can play.
  • 02 Amount to SpeedHow much? One looping clock tick. Speed and pitch move together. Uses p5.sound.
    • Touch code web editorTwo fingers. Close is slow, far apart is fast.
    • Motion code web editorThe angle. Flat is slow, upright is fast.
    • Sound code web editorHow loud. Quiet is slow, loud is fast.
  • 03 Count to VoicesHow many? Five oscillator voices of one chord. Uses p5.sound.
    • Touch code web editorEach finger on the screen adds a voice.
    • Motion code web editorEach shake adds a voice for a few seconds. Shakes are counted over time, not at one moment.
    • Sound code web editorEach clap adds a voice for a few seconds. Claps are counted over time. The voices can cover them.
  • 04 Gap to TempoWhen? A metronome on its own clock. Uses Tone.js.
    • Touch code web editorTap a steady beat.
    • Motion code web editorShake a steady beat.
    • Sound code web editorClap a steady beat.
  • 05 Dial to NoteWhich note? A sampled marimba, one note of a scale. Uses smplr.
    • Touch code web editorTwo fingers turn the dial like a knob.
    • Motion code web editorLay the phone flat and turn it.
    • Sound code web editorHum low, then high.
  • 06 Hold to SpeechHow long? The phone says how long it lasted. Longer is slower. Uses speechSynthesis.
    • Touch code web editorHold a finger down, then let go.
    • Motion code web editorHold the phone upright, then lower it. The first words must come from a tap, not a movement.
    • Sound code web editorHum for a while, then stop. The first words must come from a tap. On a speaker it may time its own voice.
